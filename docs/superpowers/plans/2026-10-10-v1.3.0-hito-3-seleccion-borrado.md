# v1.3.0 Hito 3 — Selección y borrado de elementos de estudio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Poder marcar uno o varios elementos de estudio en la lista de Studio y borrarlos de una vez, automatizando el borrado nativo (uno a uno) de Gemini Notebook, con confirmación previa y parada segura ante cualquier fallo.

**Architecture:** Cada elemento enlazado a un artefacto recibe una casilla inyectada. El panel de filtros gana una barra de acciones (Seleccionar visibles / Ninguno / Borrar (n)). Al confirmar en un modal propio, un ejecutor secuencial repite por elemento la secuencia nativa ⋮ → Eliminar → diálogo → Eliminar, localizando cada control por su texto dentro de las superposiciones de Angular Material y verificando el resultado antes de seguir.

**Tech Stack:** JavaScript clásico (MV3, sin bundler), `node:test` + jsdom con una maqueta de la UI nativa.

**Spec:** `docs/superpowers/specs/2026-10-10-v1.2.0-dom-first-source-actions-design.md`, sección "Acciones por fuente (#3)". Este plan **sustituye** la acción "Borrar visibles" por una selección explícita por elemento (petición posterior del usuario); "Seleccionar visibles" + "Borrar" cubre el caso anterior. La acción "Marcar en chat" queda para un hito 4 (necesita el DOM del panel Fuentes).

## Global Constraints

- Mantener la extensión **ligera**: sin bundler, sin dependencias nuevas en runtime.
- El borrado es **irreversible** (el flujo nativo no tiene deshacer): confirmación propia obligatoria, con foco inicial en **Cancelar**, recuento y títulos (máximo 10 y "y M más").
- **Nunca clics a ciegas**: solo se pulsa un control si su texto, sin iconos, coincide exactamente con `eliminar|borrar|delete|remove` (acción) o `cancelar|cancel` (cancelación), y se encuentra dentro de las superposiciones de Angular Material (`.cdk-overlay-container`). El diálogo de confirmación se acepta solo si contiene a la vez un botón *Cancelar* y uno *Eliminar* (su título cambia según el tipo: "Eliminar Archivo?"). Si falta algo, se **para** y se informa.
- Ejecución **secuencial**, con **Cancelar** entre elementos, **parada al primer fallo** con informe "Borrados k de N; falló en «título»: motivo", y aborto si `extensionContextLost`.
- Solo son seleccionables y borrables los elementos **enlazados a un artefacto** y **visibles** (los ocultos por un filtro se deseleccionan solos). Sin id resoluble no hay casilla.
- Tiempos como constantes con nombre: menú ≤ 2 s, diálogo ≤ 2 s, salida del DOM ≤ 8 s.
- El panel y el modal se construyen con nodos DOM y `textContent`, nunca con `innerHTML` (los títulos son datos de terceros).
- Versión `1.3.0` en `manifest.json`, `package.json` y README. El hito cierra con `npm test` en verde **y** verificación manual en el navegador real, empezando por **un elemento de prueba**.
- Fuera de alcance: borrar fuentes, "Marcar en chat" (hito 4), acciones por RPC, acciones en el popup.
- Convenciones del repo: comentarios en español **sin tildes** dentro del código (la UI sí lleva tildes); commits en español con prefijo terminados con `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`; comandos desde la raíz del worktree. Línea base: `npm test` → 83 tests, 0 fallos.

function selectionChanged() {
  if (typeof syncBulkUI === 'function') syncBulkUI();

function makeSelectBox(artifactId) {
  const wrap = document.createElement('label');
  wrap.className = 'nl-select-wrap';
  wrap.title = 'Seleccionar para borrar';
  const box = document.createElement('input');
  box.type = 'checkbox';
  box.className = 'nl-select';
  box.setAttribute('data-nl-select', artifactId);
  box.setAttribute('aria-label', 'Seleccionar elemento de estudio');
  // El clic de la casilla no debe llegar al elemento nativo (lo abriria).
  wrap.addEventListener('click', (event) => event.stopPropagation());
  box.addEventListener('change', () => {
    if (box.checked) selectedArtifactIds.add(artifactId);
    else selectedArtifactIds.delete(artifactId);
    selectionChanged();
  });
  wrap.appendChild(box);
  return wrap;
}

// Una casilla por elemento visible y enlazado a un artefacto; idempotente (no
// toca el DOM si ya esta bien) para no realimentar al MutationObserver. Los
// ids seleccionados que ya no estan visibles se descartan: lo oculto por un
// filtro nunca se borra por accidente.
function syncSelection(items, model) {
  const visible = new Set();
  items.forEach((item, index) => {
    const artifactId = model.artifacts[index].id;
    const eligible = Boolean(artifactId) && artifactMetaCache.has(artifactId) && !item.hasAttribute('hidden');
    let wrap = item.querySelector(':scope > .nl-select-wrap');
    if (!eligible) {
      if (wrap) wrap.remove();
      return;
    }
    visible.add(artifactId);
    if (wrap && wrap.firstChild.getAttribute('data-nl-select') !== artifactId) {
      wrap.remove();
      wrap = null;
    }
    if (!wrap) {
      wrap = makeSelectBox(artifactId);
      if (!item.style.position) item.style.position = 'relative';
      item.appendChild(wrap);
    }
    const box = wrap.firstChild;
    const checked = selectedArtifactIds.has(artifactId);
    if (box.checked !== checked) box.checked = checked;
    if (box.disabled !== bulkDeleteRunning) box.disabled = bulkDeleteRunning;
  });
  for (const id of Array.from(selectedArtifactIds)) {
    if (!visible.has(id)) selectedArtifactIds.delete(id);
  }
  selectionChanged();
}
```

// Recalcula el modelo y repinta casillas y botones (p. ej. al empezar o
// terminar un borrado, o al marcar "Seleccionar visibles").
function resyncSelection() {
  const panel = findStudioPanel();
  if (!panel) return;
  const items = getArtifactItems(panel);
  syncSelection(items, refreshStudyModel(items));
}

function syncBulkUI() {
  const container = document.getElementById('nl-filter-panel');
  if (!container) return;
  const count = selectedArtifactIds.size;
  const button = container.querySelector('[data-nl-action="delete-selected"], [data-nl-action="cancel-delete"]');
  if (button) {
    const action = bulkDeleteRunning ? 'cancel-delete' : 'delete-selected';
    const label = bulkDeleteRunning ? 'Cancelar' : 'Borrar (' + count + ')';
    if (button.getAttribute('data-nl-action') !== action) button.setAttribute('data-nl-action', action);
    if (button.textContent !== label) button.textContent = label;
    const disabled = !bulkDeleteRunning && count === 0;
    if (button.disabled !== disabled) button.disabled = disabled;
  }
  container.querySelectorAll('[data-nl-action="select-visible"], [data-nl-action="select-none"]').forEach((other) => {
    if (other.disabled !== bulkDeleteRunning) other.disabled = bulkDeleteRunning;
  });
}

function visibleSelectableIds() {
  const items = getArtifactItems(findStudioPanel() || document);
  const ids = [];
  items.forEach((item) => {
    const box = item.querySelector(':scope > .nl-select-wrap > .nl-select');
    if (box && !item.hasAttribute('hidden')) ids.push(box.getAttribute('data-nl-select'));
  });
  return ids;
}

function handleBulkAction(action) {
  if (action === 'select-visible') {
    visibleSelectableIds().forEach((id) => selectedArtifactIds.add(id));
  } else if (action === 'select-none') {
    selectedArtifactIds.clear();
  } else {
    return;
  }
  resyncSelection();
}

    function close(result) {
      document.removeEventListener('keydown', onKey, true);
      backdrop.remove();

const DELETE_LABEL = /^(eliminar|borrar|delete|remove)$/;
const CANCEL_LABEL = /^(cancelar|cancel)$/;
const OVERLAY_SELECTOR = '.cdk-overlay-container';
const DIALOG_SELECTOR = '[role="dialog"], [role="alertdialog"], mat-dialog-container';

// Texto de un control sin sus iconos (un mat-icon aporta texto como "delete").
function controlLabel(el) {
  const clone = el.cloneNode(true);
  clone.querySelectorAll('mat-icon, .mat-icon, svg').forEach((node) => node.remove());
  return clone.textContent.replace(/\s+/g, ' ').trim().toLowerCase();
}

function waitFor(fn, timeoutMs) {
  return new Promise((resolve) => {
    const started = Date.now();
    (function poll() {
      const value = fn();
      if (value) {
        resolve(value);
      } else if (Date.now() - started >= timeoutMs) {
        resolve(null);
      } else {
        setTimeout(poll, BULK_DELETE.stepMs);
      }
    })();
  });
}

function findItemMenuButton(item) {
  const icon = Array.from(item.querySelectorAll('mat-icon'))
    .find((el) => el.textContent.trim() === 'more_vert');
  return icon ? icon.closest('button') : null;
}

function overlayControls() {
  const roots = document.querySelectorAll(OVERLAY_SELECTOR);
  const selector = '[role="menuitem"], [mat-menu-item], .mat-mdc-menu-item, button';
  return Array.from(roots).flatMap((root) => Array.from(root.querySelectorAll(selector)));
}

// "Eliminar" de un menu desplegable: dentro de la superposicion y fuera de
// cualquier dialogo (el boton del dialogo tambien dice "Eliminar").
function findMenuDeleteEntry() {
  return overlayControls().find((el) => !el.closest(DIALOG_SELECTOR) && DELETE_LABEL.test(controlLabel(el))) || null;
}

// Boton de confirmar del dialogo de borrado. Solo se acepta un dialogo que
// tenga a la vez "Cancelar" y "Eliminar": su titulo cambia segun el tipo.
function overlayDialogs() {
  return Array.from(document.querySelectorAll(OVERLAY_SELECTOR))
    .flatMap((root) => Array.from(root.querySelectorAll(DIALOG_SELECTOR)));
}

function findDialogConfirm() {
  for (const dialog of overlayDialogs()) {
    const buttons = Array.from(dialog.querySelectorAll('button'));
    const cancel = buttons.find((b) => CANCEL_LABEL.test(controlLabel(b)));
    const confirm = buttons.find((b) => DELETE_LABEL.test(controlLabel(b)));
    if (cancel && confirm) return confirm;
  }
  return null;
}

function dialogIsOpen() {
  return overlayDialogs().length > 0;
}

// Borra UN elemento con la UI nativa: ⋮ -> Eliminar -> dialogo -> Eliminar.
// Nunca pulsa a ciegas: si falta o sobra algo, devuelve el motivo y no sigue.
async function deleteOneArtifact(item) {
  if (!item || !item.isConnected) return { ok: false, reason: 'el elemento ya no está en la lista' };
  const originalTitle = normalizeTitle(getTitle(item));
  const trigger = findItemMenuButton(item);
  if (!trigger) return { ok: false, reason: 'no encuentro el menú ⋮ del elemento' };
  if (findMenuDeleteEntry() || dialogIsOpen()) {
    return { ok: false, reason: 'ya hay un menú abierto; ciérralo y reintenta' };
  }

  trigger.click();
  const entry = await waitFor(findMenuDeleteEntry, BULK_DELETE.menuMs);
  if (!entry) return { ok: false, reason: 'no se abrió el menú o no tiene la opción Eliminar' };

  entry.click();
  const confirm = await waitFor(findDialogConfirm, BULK_DELETE.dialogMs);
  if (!confirm) return { ok: false, reason: 'no apareció el diálogo de confirmación esperado (con Cancelar y Eliminar)' };

  confirm.click();
  const gone = await waitFor(
    () => !item.isConnected || normalizeTitle(getTitle(item)) !== originalTitle,
    BULK_DELETE.goneMs
  );
  if (!gone) return { ok: false, reason: 'el elemento no desapareció de la lista tras confirmar' };
  return { ok: true };
}

### Seleccionar y borrar elementos de estudio

- Cada elemento de la lista lleva una **casilla** (arriba a la izquierda). Solo la tienen los elementos enlazados a un artefacto.
- **Seleccionar visibles** marca todo lo que deja pasar el filtro actual; **Ninguno** lo desmarca. Lo que un filtro oculte se deselecciona solo: nunca se borra algo que no ves.
- **Borrar (n)** pide una confirmación con el recuento y los títulos y, si aceptas, repite por cada elemento la secuencia nativa (⋮ → Eliminar → confirmar). Se detiene al primer fallo e indica cuántos se borraron. **Cancelar** detiene el proceso tras el elemento en curso.
- El borrado es **irreversible**: Gemini Notebook no permite deshacerlo.
```
