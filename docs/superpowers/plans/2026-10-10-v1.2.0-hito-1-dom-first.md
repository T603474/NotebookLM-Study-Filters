# v1.2.0 Hito 1 — Modelo DOM-first Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que el panel de filtros refleje siempre lo que existe en Studio: al borrar un elemento, chips, contadores, "Mostrando N de M" y filtros guardados se corrigen solos; las fuentes pasan a identificarse por UUID.

**Architecture:** Una función pura `buildStudyModel` (en `filter-core.js`) construye, en cada pasada, el modelo de lo que hay *ahora* en el DOM (artefactos, fuentes por UUID, recuentos). `content.js` renderiza chips, contadores y filtros desde ese modelo; la caché de red solo es un diccionario. Una segunda función pura, `reconcileSourceFilter`, migra las claves antiguas `Tnnn` a `ID:<uuid>` y poda las fuentes que ya no existen.

**Tech Stack:** JavaScript clásico (MV3, sin bundler), `node:test` + jsdom para las pruebas.

**Spec:** `docs/superpowers/specs/2026-10-10-v1.2.0-dom-first-source-actions-design.md` (este plan cubre el **hito 1**: H1–H5, H7–H8; los hitos 2 y 3 tienen plan propio).

## Global Constraints

- Mantener la extensión **ligera**: sin bundler, sin dependencias nuevas en runtime.
- Identidad de fuente por **UUID**: el valor del chip es `ID:<uuid>`; se reutiliza `SOURCE_ID_PREFIX` y la lógica existente de `matchesSourceQuery`.
- Texto de chip de fuente: nombre real; si se desconoce, el número de tema derivado; si tampoco hay, `Fuente sin nombre · <4 caracteres del uuid>`; si dos fuentes comparten texto, se añade ` · <4 caracteres del uuid>`.
- Migración y poda del filtro guardado **solo** cuando `model.complete` (≥1 elemento y todos con metadatos): no se debe perder la selección mientras el DOM o la red aún cargan.
- El panel se construye con nodos DOM y `textContent`, nunca con `innerHTML` concatenado (H8).
- Fuera de alcance: borrar fuentes, acciones por RPC, acciones en el popup, eliminar `INLINE_FILTER_CORE` (se mitiga con un test de paridad).
- Versión `1.2.0` en `manifest.json`, `package.json` y README. El hito cierra con `npm test` en verde **y** verificación manual en navegador real (jsdom no reprodujo el bug de la 0.1.6).
- Convenciones del repo: comentarios en español **sin tildes** dentro del código (texto de UI sí lleva tildes); commits en español con prefijo (`feat:`, `fix:`, `test:`, `docs:`, `refactor:`) terminados con `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Todo comando se ejecuta desde la raíz del worktree. Preparación (una vez): `npm ci`. Línea base verificada: `npm test` → 44 tests, 0 fallos.

## Review Focus

Entradas o situaciones que el spec implica pero que ninguna tarea de comportamiento principal cubre, de más a menos probable de afectar a quien use la extensión:

1. Un título del DOM que difiere del de la red solo en espacios o mayúsculas no debe desenlazar el elemento (si no, el filtro por fuente deja de funcionar). → test en Tarea 4.
2. Al cargar la página el DOM se pinta antes de que lleguen los metadatos: la fuente seleccionada y guardada **no** debe podarse. → test en Tarea 6.

  // Claves de tema derivables de un texto (titulo de fuente o de artefacto):
  // la primera clave numerica ("047.md", "T047", "Tema41_...") y, ademas, la de
  // un "Tema NN" explicito. Misma logica que content.js usaba en
  // extractSourceKeysFromText.
  function extractSourceKeys(text) {
    const keys = new Set();
    if (!text) return keys;
    const coreKey = sourceKeyFromTitle(text);
    if (coreKey) keys.add(coreKey);
    const tema = String(text).match(/\btema[\s_]*0*(\d{2,3})(?!\d)/i);
    if (tema) {
      const key = normalizeSourceQuery(tema[1]);
      if (key) keys.add(key);
    }
    return keys;
  }

  function shortId(id) {
    return String(id).slice(0, 4);
  }

  // Modelo de lo que existe AHORA en el panel de Studio (spec v1.2.0). El DOM
  // decide que artefactos existen; el diccionario de red solo aporta sus
  // fuentes y los titulos de fuente. Funcion pura: no toca DOM ni chrome.*.
  //
  //   domItems: [{ id, title, kind }]   (id '' si el item no esta enlazado)
  //   dict:     { artifacts: Map<id, {sourceIds, title}>,
  //               sourceTitles: Map<sourceId, title> }
  function buildStudyModel(domItems, dict) {
    const artifactDict = (dict && dict.artifacts) || new Map();
    const sourceTitles = (dict && dict.sourceTitles) || new Map();
    const byKind = {};
    const bySourceId = {};
    const titleKeysBySource = new Map();
    const sourceOrder = [];
    const artifacts = [];
    let unlinked = 0;

    for (const item of domItems || []) {
      const meta = item.id ? artifactDict.get(item.id) : null;
      if (!meta) unlinked += 1;
      const sourceIds = meta ? Array.from(new Set(meta.sourceIds || [])) : [];
      const titleKeys = extractSourceKeys((meta && meta.title) || item.title);
      for (const sourceId of sourceIds) {
        bySourceId[sourceId] = (bySourceId[sourceId] || 0) + 1;
        if (!titleKeysBySource.has(sourceId)) {
          titleKeysBySource.set(sourceId, new Set());
          sourceOrder.push(sourceId);
        }
        titleKeys.forEach((key) => titleKeysBySource.get(sourceId).add(key));
      }
      const kind = item.kind || 'other';
      byKind[kind] = (byKind[kind] || 0) + 1;
      artifacts.push({ id: item.id || '', title: item.title || '', kind, sourceIds });
    }

    const sources = sourceOrder.map((id) => {
      const name = sourceTitles.get(id) || '';
      const keys = new Set(extractSourceKeys(name));
      titleKeysBySource.get(id).forEach((key) => keys.add(key));
      const sortedKeys = Array.from(keys).sort();
      const label = name
        || (sortedKeys[0] ? sortedKeys[0].replace(/^T/, '') : '')
        || 'Fuente sin nombre · ' + shortId(id);
      return { id, name, nameKnown: Boolean(name), keys: sortedKeys, label };
    });

    const labelUses = new Map();
    sources.forEach((source) => labelUses.set(source.label, (labelUses.get(source.label) || 0) + 1));
    sources.forEach((source) => {
      if (labelUses.get(source.label) > 1) source.label += ' · ' + shortId(source.id);
    });
    sources.sort((a, b) => a.label.localeCompare(b.label, undefined, { numeric: true }));

    const sourceById = new Map(sources.map((source) => [source.id, source]));
    for (const artifact of artifacts) {
      const keys = new Set();
      const names = [];
      for (const sourceId of artifact.sourceIds) {
        const source = sourceById.get(sourceId);
        source.keys.forEach((key) => keys.add(key));
        if (source.name) names.push(source.name);
      }
      artifact.sourceKeys = Array.from(keys).sort();
      artifact.sourceNames = names;
    }

    return {
      artifacts,
      sources,
      counts: { byKind, bySourceId, total: artifacts.length },
      complete: artifacts.length > 0 && unlinked === 0,
    };
  }
